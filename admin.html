Cloud sync

This site talks to a small secure proxy (a Cloudflare Worker) that holds the one-time GitHub credential privately on the server side. Every admin just signs in with their authorized Google account, so nobody needs to see or paste a token. When you approve typos or update scores, your request is verified against the live admin list, then committed to GitHub automatically, which recalculates scores and redeploys the leaderboard for everyone. See cloudflare-worker/README.md for the one-time setup (done once, by the site owner only).

Advanced: legacy personal access token fallback

Only use this if the Cloud Sync Worker above is unavailable. Pasting a token here stores it in your browser only and lets this device commit directly to GitHub, but it must be re-entered on every device and by every admin, which is exactly what the Worker avoids.
