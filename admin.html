☁️ Cloud Sync (Secure — No Token Sharing Required)

This site talks to a small secure proxy (a Cloudflare Worker) that holds the one-time GitHub credential privately on the server side. When you approve typos or update scores, your request is verified against the live admin list, then committed to GitHub automatically, which recalculates scores and redeploys the leaderboard for everyone.
